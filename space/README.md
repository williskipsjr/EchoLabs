# EchoLabs web demo

Upload two songs: EchoLabs takes the vocals from the first and the instrumental from the second, separates both with Demucs, matches tempo beat-by-beat and transposes to a compatible key.

Source code, benchmarks and method: https://github.com/williskipsjr/EchoLabs

Only upload music you own or have permission to remix. Every output includes a provenance manifest naming its sources.
